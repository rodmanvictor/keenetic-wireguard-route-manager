# Screenshots

Изображения интерфейса PackeTech, которые используются в корневом README.

- `paketych-connect.png` — первый запуск и подключение к Keenetic.
- `paketych-domains.png` — список доменов и найденных маршрутов.
- `paketych-vpn.png` — управление профилями WireGuard.
- `packetech-cli.png` — справка реальной команды `packetech --help` в терминальном макете.
- `packetech-tui.png` — главное меню реального режима `packetech tui`.

Терминальные изображения пересобираются командой
`PYTHONPATH=src .venv-build/bin/python scripts/render-terminal-screenshots.py`.
