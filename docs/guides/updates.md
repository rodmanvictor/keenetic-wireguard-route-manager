# Обновление PackeTech

PackeTech проверяет новые версии на GitHub после входа в приложение. Проверка
не мешает подключению к роутеру: если интернет или GitHub недоступны, маршруты
продолжают работать как обычно.

## Если вышла новая версия

Под верхней панелью появится зелёное сообщение. Нажмите **Скачать**. PackeTech:

1. выберет сборку для вашей операционной системы и процессора;
2. скачает файл в папку `Загрузки`;
3. сверит его контрольную сумму SHA-256;
4. откроет файл штатным способом.

Последний шаг зависит от системы:

- **Windows:** закройте PackeTech, распакуйте новый ZIP и замените старую папку;
- **Linux:** подтвердите обновление DEB в системном установщике;
- **macOS:** перетащите PackeTech из DMG в папку `Программы` с заменой.

Настройки роутера, пароль и список доменов хранятся отдельно от программы и при
обновлении сохраняются.

## Проверить вручную

Нажмите значок обновления в правой части верхней панели. Откроется окно с
установленной и последней доступной версиями.

PackeTech не устанавливает файл скрытно и не запрашивает пароль администратора
самостоятельно. Подтверждение установки остаётся за операционной системой.
