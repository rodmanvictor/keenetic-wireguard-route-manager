# Установка в Windows

## Шаг 1. Скачать

Скачайте [PackeTech для Windows](https://github.com/rodmanvictor/packetech/releases/download/v0.3.1/packetech-0.3.1-windows-x86_64.zip).

Архив рассчитан на 64-битные Windows 10 и 11. Python, Git и другие программы
не нужны.

## Шаг 2. Распаковать

Нажмите на ZIP правой кнопкой → **«Извлечь всё»**. Не запускайте программу
прямо из архива и не переносите отдельные EXE: графическая и фоновая части
работают вместе.

## Шаг 3. Запустить

Откройте распакованную папку и запустите `PackeTech.exe`.

Сборка пока не подписана платным сертификатом. Если SmartScreen покажет
предупреждение, нажмите **«Подробнее»** → **«Выполнить в любом случае»**.

## Шаг 4. Подключить Keenetic

Введите адрес роутера, логин и пароль администратора. Обычно адрес —
`192.168.1.1`, логин — `admin`. Пароль сохраняется в пользовательском файле,
поэтому повторно вводить его не придётся.

После первого входа PackeTech создаст в Планировщике заданий задачу
`PackeTech route sync`. Она обновляет DNS-маршруты каждые 6 часов.

## Командная строка

Откройте PowerShell в папке программы:

```powershell
.\PackeTech-CLI.exe status
.\PackeTech-CLI.exe add example.com --tunnel wg1
.\PackeTech-CLI.exe tui
```

Все команды описаны в [руководстве по терминалу](terminal.md).

## Где лежат данные

- профиль и пароль: `%APPDATA%\KeeneticRouteManager\config.json`;
- домены и история: `%LOCALAPPDATA%\KeeneticRouteManager\route-sync.sqlite3`.

Пароль записан в JSON без шифрования. Не отправляйте этот файл другим людям.
