# Первый запуск и импорт WireGuard

## CLI

```bash
kwan setup
```

Введите пароль администратора Keenetic. Программа сохранит адрес, логин и пароль
в пользовательском JSON с правами `600`. Для другого адреса:

```bash
kwan --host 192.168.50.1 --user admin setup
```

Для скрипта пароль можно передать только через переменную окружения:

```bash
export MY_KEENETIC_PASSWORD='...'
kwan --password-env MY_KEENETIC_PASSWORD status
```

Не помещайте пароль прямо в команду или shell history.

## Установка компонентов

Обычный `setup` лишь показывает состояние. Если SSH или WireGuard доступны для модели, но не установлены:

```bash
kwan setup --install-components --confirm-reboot
```

Во время `components commit` соединение может оборваться. Дождитесь загрузки роутера и снова выполните `kwan setup`.

## Импорт конфигурации

Проверка без изменения роутера:

```bash
kwan tunnel import --file vpn.conf --show-plan
```

В плане закрытый и preshared-ключи заменены на `***`. Применение:

```bash
kwan tunnel import --file vpn.conf --name srv01 --via ISP --confirm
```

Для QR:

```bash
kwan tunnel import --qr vpn.png --name srv01 --confirm
```

Поддерживается стандартный формат WireGuard с `[Interface]` и одним или несколькими `[Peer]`. Выбирается первый IPv4 `Address`; IPv6 `AllowedIPs`, DNS и MTU пока не применяются. Существующий интерфейс не перезаписывается: по умолчанию выбирается первый свободный `WireguardN`. При ошибке частично созданный новый интерфейс удаляется.

После импорта проверьте туннели и добавьте домен:

```bash
kwan status
kwan add example.com --tunnel wg2
```

## Desktop

На первом экране введите адрес, логин и пароль. После подключения доступны:

- состояние SSH/Telnet и компонентов;
- установка отсутствующих SSH/WireGuard с подтверждением перезагрузки;
- импорт `.conf` или изображения QR;
- выбор обнаруженного туннеля при добавлении домена;
- список доменов с favicon, выбранным туннелем и источниками;
- включение и отключение домена без ручной работы с IP;
- техническое окно с объяснением DNS IP и CIDR;
- ручное обновление всех доменов.

Над списком расположена форма быстрого добавления: вставьте домен или полный
URL и нажмите `+` либо Enter. Приложение само извлечёт hostname. При одном VPN
маршрут применяется сразу; при нескольких открывается выбор по пользовательским
названиям из Keenetic. Идентификаторы `wgN` и `WireguardN` остаются мелкой
технической подписью.

Кнопка «Настройка VPN» открывает список интерфейсов с живым состоянием. Отсюда
профиль можно переименовать, включить, отключить или удалить. Удаление
блокируется, если на профиль ссылается хотя бы один включённый домен.

Экран входа разделён на две части: слева расположен Пакетыч, справа — поля
подключения. Во время проверки кнопка остаётся на месте, блокируется и показывает
индикатор внутри себя.

Favicon загружаются через внешний Google S2 endpoint. Это best-effort-функция:
при сетевой ошибке интерфейс показывает первую букву домена. Endpoint получает
только имя домена и размер изображения.

После обратной инвентаризации приложение связывает известные сервисы rucens с
явно заданными DNS-доменами. Связь создаётся автоматически только тогда, когда
все маршруты сервиса используют один `WireguardN`. Если сервис встречается в
нескольких туннелях или для него нет проверенного доменного соответствия,
приложение не угадывает выбор пользователя.

Если локальная база установленного приложения пуста, обратная инвентаризация
запускается автоматически после первого успешного входа. Она только читает
маршруты. После входа также включается пользовательский systemd-таймер с
интервалом 6 часов.
