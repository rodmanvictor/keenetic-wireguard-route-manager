# Расширение Chrome

Расширение **«PackeTech · открыть сайт»** добавляет домен текущей вкладки в
общую базу. Сейчас связь с локальным приложением поддерживается в Linux.

## Шаг 1. Скачать исходный код

Скачайте архив проекта на странице
[GitHub Releases](https://github.com/rodmanvictor/packetech/releases/latest) и
распакуйте его.

## Шаг 2. Добавить расширение

1. Откройте `chrome://extensions`.
2. Включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»**.
4. Выберите папку `integrations/chrome/extension`.
5. Скопируйте 32-символьный ID с карточки расширения.

## Шаг 3. Подключить локальный помощник

В корне распакованного проекта выполните:

```bash
python3 -m venv .venv-chrome
.venv-chrome/bin/python -m pip install -e .
./scripts/install-native-host-linux.sh ID_ИЗ_CHROME .venv-chrome/bin/python
```

Вернитесь в `chrome://extensions`, включите переключатель PackeTech и закрепите
значок на панели.

Круглая стрелка только перечитывает файлы включённого расширения. Если на
карточке написано `Off`, включите переключатель справа. После повторной загрузки
папки ID может измениться — тогда установите native host ещё раз с новым ID.

## Как пользоваться

Откройте нужный сайт, нажмите значок PackeTech и выберите добавление домена.
Источник `Chrome` появится в графическом приложении. Общий IP не удалится, если
тот же адрес нужен домену из другого источника.
