# Расширение Chrome

Расширение **«PackeTech · открыть сайт»** добавляет открытый сайт и недоступные
ресурсы страницы в маршруты одной кнопкой. Логин, пароль, адрес роутера и путь
к базе вводить повторно не нужно: расширение работает через установленное
приложение PackeTech.

## Установка через PackeTech

### Шаг 1. Подключитесь к роутеру

Запустите PackeTech и войдите в Keenetic как обычно. Приложение должно показать
список сайтов и настроенный VPN.

### Шаг 2. Запустите установку

В верхней части PackeTech нажмите **Chrome** → **Установить расширение**.

Программа сама:

- проверит, установлен ли Google Chrome;
- положит расширение в постоянную пользовательскую папку;
- зарегистрирует локальный помощник PackeTech;
- откроет страницу `chrome://extensions`;
- откроет папку, которую нужно выбрать.

### Шаг 3. Подтвердите расширение в Chrome

На странице расширений:

1. Включите **Режим разработчика** в правом верхнем углу.
2. Нажмите **Загрузить распакованное расширение**.
3. Выберите папку, которую открыл PackeTech.
4. Включите переключатель на карточке **PackeTech · открыть сайт**.
5. Нажмите значок пазла рядом с адресной строкой и закрепите PackeTech.

Это единственная часть, которую нельзя выполнить автоматически: Chrome требует,
чтобы пользователь сам подтвердил установку распакованного расширения.

## Как пользоваться

1. Откройте сайт, который не загружается, и обновите страницу.
2. Нажмите усатый значок PackeTech рядом с адресной строкой.
3. Расширение покажет связанные домены, с которых не загрузились картинки,
   скрипты, стили или API. Снимите галочки с тех, которые добавлять не нужно.
4. Нажмите **Добавить через VPN**.

PackeTech добавит домен в общую SQLite-базу, сам выберет уже используемый
WireGuard-профиль и обновит маршруты. Сайт останется в шестичасовом
автообновлении и появится в приложении с источником **Chrome**.

### Какие ошибки попадают в список

PackeTech предлагает только ошибки, которые может исправить другой маршрут:

- блокировку доступа `403` или `451`;
- ошибки DNS;
- тайм-аут, обрыв или отказ соединения;
- ошибки VPN/прокси и некоторые ошибки CDN `5xx`.

`404 Not Found` не попадает в список: адрес отсутствует на самом сервере, и VPN
его не вернёт. Также расширение не предлагает запросы, отменённые страницей,
заблокированные рекламным фильтром, CSP или проверкой сертификата.

Для поиска недоступных картинок и API расширению нужен доступ к адресам сетевых
запросов страницы. Оно сохраняет во временном хранилище Chrome только домен,
тип ресурса и причину ошибки. Тело страницы, содержимое запросов и историю
посещений PackeTech не читает. Данные вкладки удаляются после её закрытия.

## Если расширение не запускается

- На карточке написано **Off** — включите переключатель справа. Круглая стрелка
  только перечитывает файлы и не включает выключенное расширение.
- Chrome пишет, что помощник не найден — откройте PackeTech, нажмите
  **Chrome** → **Установить расширение** еще раз, затем перезагрузите карточку.
- После обновления расширения список ресурсов пуст — один раз перезагрузите
  нужную страницу: фоновой помощник увидит только новые запросы.
- Папка потерялась — нажмите **Chrome** → **Показать папку**.
- PackeTech не находит Chrome — установите обычный Google Chrome и повторите
  установку из программы.

## Ручная установка для разработчиков

Если PackeTech запущен из исходного кода, расширение можно загрузить из папки
`integrations/chrome/extension`. Для обычной установки этот способ не нужен.
